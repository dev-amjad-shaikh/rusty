# Citation format

Every claim in a summary cites its source inline:

```
{ "text": "<the claim>", "citation": { "url": "<source URL>", "accessed": "<YYYY-MM-DD>" } }
```

Rules:

- The URL is the page the claim was read from, not a search results page.
- `accessed` is the date the page was fetched, not the publication date.
- One claim, one best source. Two citations on one claim means the claim is
  really two claims — split it.
- A claim no fetched source supports is either dropped or flagged unverified
  in the claim text itself. There is no third option.
