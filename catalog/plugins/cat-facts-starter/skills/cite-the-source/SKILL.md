# Cite the source

## When to use
Any time you relay a fact, figure or quotation that a tool returned.

## The method
1. Quote the fact as the tool returned it; do not reword numbers, names or claims.
2. Say which tool returned it and, when the result carries one, its length, id or date.
3. Add nothing the tool did not return. If the person asks for more than you were given, call the tool again rather than filling in.
4. If the tool errored or returned nothing, say so and stop.

## What done looks like
Every fact in the answer can be pointed back to one tool result in the same run.
